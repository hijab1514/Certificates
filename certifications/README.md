## How to Add a New Certification
1. Choose the correct category directory under `/certifications`.
2. Create a file using a consistent name format:
   - `YYYY-MM-certification-name.md`
   - Example: `2026-08-introduction-to-machine-learning.md`
3. Fill all template fields using factual information only.
4. Add or link the certificate file in `/assets` (or a category-specific subfolder).
5. Add a row to this master table.
6. Add the certification to the category README table.
7. Update root `README.md` sections (statistics, featured certifications, skills) as needed.

## Verification Guidance
Prefer official verification pages from issuing organizations (credential platforms, institution records, or vendor verification URLs). If no public verification exists, clearly mark the entry as `Verification unavailable` and include only non-sensitive details.
